\section{Example evaluation input}
\label{app:prompt}
The system instruction for all solve and evaluation calls was:
\begin{quote}\small
Each task is a directed unit-cost graph. Traverse only listed edges in their direction. A locked edge (requires\_key:true) needs the key. You acquire it permanently on first visiting key\_at, including at the start. null means no key. Solve every task. Return \texttt{\{answers:\{id:\{path:[start,...,goal]\}\}\}}. Use \texttt{\{unreachable:true\}} for an unreachable goal. Paths must be shortest.
\end{quote}
The user message contained the ordered memory and task lists.
Each stored example added its verified solution to the task fields.
The following is one original E002 key-detour query, reformatted
for readability. Its family label was used for scoring only.
\begin{verbatim}
ID: h03, start: A, goal: B, key_at: C
Directed edges: D->B (locked), B->F, C->D, F->E, D->F, D->C, A->D
An optimal path: A->D->C->D->B
\end{verbatim}
The actual JSON bodies, retained memories, and raw outputs are
in the archived call traces.
