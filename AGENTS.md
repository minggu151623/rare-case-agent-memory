# Research workflow

Read [research-state.yaml](research-state.yaml), [findings.md](findings.md),
and the active experiment protocol before continuing.

This project uses Orchestra Research's
[autoresearch](https://github.com/Orchestra-Research/AI-Research-SKILLs/tree/773a52944ba4747a18bd4ae9ade53fff041adcbc/0-autoresearch-skill)
workflow. The bootstrap applied problem reformulation from
[creative-thinking-for-research](https://github.com/Orchestra-Research/AI-Research-SKILLs/tree/773a52944ba4747a18bd4ae9ade53fff041adcbc/21-research-ideation/creative-thinking-for-research).
Consult the pinned skill sources when resuming or changing phases.

Commit each finalized protocol before generating its results. Record deviations,
exploratory analyses, and negative outcomes in the experiment directory.
Update the state, decision log, and findings at meaningful checkpoints.
Keep evaluation fixtures and outputs out of the model's example memory.
